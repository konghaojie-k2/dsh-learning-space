# 学习空间（dsh-learning-space）

把 typora-next 的「AI 课程模式」核心能力搬进 DeepSeek Harness Web UI 的插件：

- **AI 生成课程（多步流水线）**：输入主题/领域/难度/章节数，先由模型生成大纲；每章再按「规划小节 → 分段撰写 → 提取概念 → 生成测验 → 结构与元素校验 → 定向修复 → 保存」执行，界面上能看到每一步的实时进度，可取消；章节任务可恢复，生成失败会保留错误位置。
- **章节阅读 + KaTeX 数学渲染**：按章阅读，`$$...$$` / `\[...\]` / `\(...\)` / 行内 `$...$` 公式由 KaTeX 渲染；标记完成、上一章/下一章。
- **进度写回课程文件**：学习进度、测验成绩、复习排期写入 `course.json` 的 `progress` 字段；复制/备份整个 `~/Documents/学习空间` 即可跨设备带走进度。浏览器 `localStorage` 只做离线镜像。
- **知识图谱**：基于课程大纲概念生成概念关系图（前置 / 相关 / 对比），用典型的力导向 Node-Link 网络图展示 —— 节点按章节配色与度数定大小、可缩放/拖动画布、拖动节点、hover 高亮邻居并显示 tooltip、点击节点看概念详情与前置/后继/相关概念、支持「适应画布 / 重新布局 / 重新生成图谱」；d3 加载失败时回退为圆形简化布局。
- **渐进解锁**：课程可设「初始解锁章节数」（默认 2）、「掌握度门槛」（默认 70%）与「每阶段章节数」（默认 3）；完成上一章 + 章末测验达标 + 该章概念掌握达标，才逐章解锁下一章；阶段边界还要通过阶段综合测评（默认 ≥70%）才能进入下一阶段；锁定章节不能阅读/生成，解锁条件在界面里逐项显示。
- **阶段测评**：每 N 章自动组成一个阶段，阶段内章节全部解锁后可生成 5 道综合测评题（覆盖全阶段概念、跨章联系）；提交后计入概念掌握度，通过后解锁下一阶段；「掌握度」tab 里显示每个阶段的通过状态，可重新测评。
- **掌握度与概念绑定**：每章生成 `concepts.json`（概念定义/先修/难度）；测验题绑定具体概念；答题结果由 Host 计算到 `progress.concepts`（累计正确率）；课程/章节/概念掌握度在「掌握度」tab 展示，并作为解锁依据。
- **划词标注与自由讨论**：阅读器里选中任意文本（不要求落在知识点上）即可高亮 / 下划线 / 加备注，支持 5 种颜色；一条标注可以**追加多条备注**并逐条删除，标注与备注持久化到 `annotations.json`，点击标注可改色、追加备注或删除。任意选区也可以「解释」「辨析」「画示意图」；只有「我不懂」需要先选概念（因为它要写回掌握度模型）。
- **划词互动**：在阅读器里选中文本，可以「解释」「辨析」「画示意图」「我不懂」；解释/辨析/示意图由当前模型生成（结合本章上下文与概念关系），结果存 `interactions.json`，可继续追问或重画。选中/概念可标记「没懂/有点模糊/已理解」，会修正该概念的有效掌握度并影响解锁判定。
- **学习记录**：课程详情新增「记录」tab，按时间汇总讨论记录（解释/辨析/示意图的原文与回答，可展开重看）与阅读标注（高亮/下划线/备注，可跳回原文）；互动面板里也有「历史 N」入口，可回看本章之前的问答。
- **错题本与错题重练闭环**：错题本按章节/概念汇总测验错题（正确项/你的选择/解析）；每道错题可「重做」或生成同知识点「变式题」，提交后按题目绑定概念累计掌握度；答对后标记「已订正」，错题本角标按未订正数变化，今日学习计划也会出现「订正 N 道错题」。
- **学习计划排期与提醒**：课程详情新增「计划」tab，可把建议任务一键填入计划、指定截止时间、关联章节；任务按逾期 / 今天 / 未来 / 已完成分组，可勾选完成、改期、删除；到期任务会在页面顶部提醒，并可选择开启系统桌面通知。
- **结课证书**：当课程全部完成、掌握度达标且没有“没懂”概念时，显示结课/证书资格。
- **间隔复习**：按 1/3/7/14/30 天排期（得分低于 60% 重置到 1 天），复习 tab 显示到期/未排期/未到期，可直接复做章末测验并自动更新下次复习时间。
- **章末测验**：每章 3 道中文单选题，作答后给出得分、正误标记与解析（首次测验与复习共用一套排期）；阅读器里默认折叠，点开才展开。
- **代码高亮与特别文本**：Prism 语法高亮（Python/JS/TS/Bash/JSON/SQL/Rust/Go/Java/C/C++/C#/YAML/Markdown/HTML/PHP/PowerShell 等），代码块带语言标签、行号、行数、复制按钮、上下/左右滚动阴影，超过 16 行默认折叠；`> [!tip]` / `[!warning]` / `[!concept]` / `[!question]` / `[!answer]-` 提示框、引用、行内代码、表格斑马纹、分隔线都有专门样式。
- **Mermaid 图**：```mermaid 代码块按需懒加载 Mermaid（3.2MB 只在首次出现时加载），支持 flowchart / sequenceDiagram / mindmap 等；渲染为独立图表卡片：紫色左侧强调边、`Mermaid` + 图表类型徽标（流程图/时序图/ER 图等）、「查看源码 / 收起源码」切换，与正文和普通 SVG 插图区分明显；图随明暗主题自动重渲染。
- **内联 SVG 插图**：正文里的 `<svg viewBox="0 0 680 400">…</svg>` 与 ```svg 围栏会渲染成浅底插图卡片；工科/人文章节生成时 AI 会自动配 1 张设备剖面/工艺流程/场景示意图（缺图时 Host 会补生成，客户端对 SVG 做脚本/事件/外链清洗）。
- **深色主题**：代码 token、callout、表格、公式卡、测验、复习、图谱、SVG/Mermaid 外框都有专门深色适配。

## 安装（npm）

本包是 **DeepSeek Harness 的 Cordis bundle**，不是独立应用；安装到 Harness profile 后，刷新 Web UI 即可在侧边栏看到「学习空间」。

```bash
cd ~/.dsh/profiles/desktop
pnpm add dsh-learning-space
```

然后在 `~/.dsh/profiles/desktop/package.json` 的 `dsh.profile.bundles` 数组中加入：

```json
"dsh-learning-space"
```

重启 DeepSeek Harness，并刷新 Web UI 页面。若从本地 tarball 安装，用 `pnpm add /path/dsh-learning-space-0.13.3.tgz` 代替上面的包名即可。

## 使用


1. 插件安装/更新后，刷新 Harness 页面（Web UI 已在运行时必须刷新一次，新的客户端代码才会生效）。
2. 左侧边栏的全局面板图标里出现 **学习空间**，点击进入主面板。
3. 「新建课程」→ 填主题/章节数/初始解锁章节数/掌握度门槛 → 「生成大纲」→ 「生成全部章节」（只生成已解锁章节）。
4. 课程详情有 **章节 / 知识图谱 / 复习 / 掌握度 / 计划 / 记录**（有错题时还有 **错题本**）；锁定章节会显示解锁条件。进入某门课程后左侧课程列表会自动折叠，点顶部「课程列表」可展开，点列表右上角「«」可再次折叠。
5. 学完一章后作答章末测验（每题标注考察的概念），达标即解锁下一章；「掌握度」里能看到总掌握度、逐章掌握度与最薄弱概念。知识图谱按概念自动生成，锁定章节的概念会以锁定样式显示。

课程文件保存在 `~/Documents/学习空间/<courseId>/`：

```
course.json              # 课程元数据 + 大纲 + progress（完成/测验/复习排期）+ 已生成章节
chapters/01.md           # 章节正文（Markdown，含 LaTeX 公式）
chapters/01.quiz.json    # 章末测验（每题绑定 concepts）
chapters/01.concepts.json# 本章概念（定义/先修/难度）
assessments.json         # 各阶段综合测评题缓存
retrain-variants.json    # 错题变式题缓存
interactions.json        # 划词解释/辨析/示意图的互动历史
annotations.json         # 高亮/下划线/备注（按章节 + 文本锚点持久化）
graph.json               # 知识图谱（来自各章概念，锁定章节节点标记 locked）
```

可以直接用编辑器打开、修改或备份这些文件；删除课程会删除对应目录。

## 说明与边界

- 模型：使用 Harness 当前默认模型（`agentDefaultModel`），不需要在插件里单独配置 API Key。
- 数学：KaTeX 0.16.9 随插件存放在 `vendor/katex/`，通过 `/learning-space/vendor/` 同源加载；加载失败时公式降级为原文，不影响阅读。
- 代码高亮：Prism 及 20 种语言随插件存放在 `vendor/prism/prism-bundle.min.js`（同源加载）；Prism 不可用时降级为无高亮纯文本，复制在浏览器拒绝剪贴板时静默失败。
- Mermaid：`vendor/mermaid/mermaid.min.js` 随插件存放，**只在实际出现 mermaid 图时懒加载**（3.2MB，首次会短暂 loading）；渲染失败会降级为代码块并提供重试。
- 知识图谱使用 d3 v7（`vendor/d3/d3.v7.min.js`，约 279KB），只在打开图谱页时懒加载；节点标签会截断到约 8 个汉字（完整名称见 tooltip/悬停标题）。
- 内联 SVG：客户端用 DOMParser 清洗（删除 script/style/foreignObject/iframe/image/a、`on*` 事件、`javascript:` 与外链 href，必须有 viewBox）后才注入；清洗失败会显示降级提示，不会白屏。
- SVG 插图由模型生成，偶尔可能信息密度不足或排版一般；重新生成该章即可换一张。
- 知识图谱：节点来自大纲里的概念（去重；没有概念的章节用章标题），关系边由模型生成；模型失败时回退为「同章顺序链 + 跨章前置」的派生关系，并提示可重新生成。图谱按需生成，不是每门课自动生成。
- 复习排期在客户端计算后写回 `course.json`；多台设备同时打开同一 `Documents/学习空间` 会以后写入者为准（没有做冲突合并）。
- 进度同步是「本地立即生效 + 450ms 防抖写回 + 失败指数退避重试」；离线时先保存在 localStorage，恢复后自动补写。
- 章节内容只在解锁后才生成（锁定章节不预生成）；解锁在写回 `progress` 时由 Host 计算，客户端立即刷新锁状态。
- 掌握度口径：概念掌握 = 该概念相关题累计正确率；章节掌握 = 本章概念平均；课程掌握 = 有答题记录的概念平均；复习答题同样累计。
- 生成语义：章节内容只在解锁后才生成；已生成章节可「重读/重做测验」，重做会累计到概念掌握度（累计正确率，不取最后一次）。
- 暂未实现：苏格拉底式追问复习、案例研习、跨课程学习档案、结课路线/证书导出。这些是后续迭代方向。
- 生成的测验题可能在极少数情况下格式不合法，此时该章仍会保存正文，测验显示为「暂无测验」，可重新生成该章。

## 开发

- 宿主半：`index.js`，注册 `POST /learning-space/api`（action 分发）、`GET /learning-space/health`、`GET /learning-space/vendor/*`（KaTeX 静态资源）。
- 客户端半：`client.js`，通过 ModuleLoader 注册 `sidebar.panellist` 图标和 `main` 面板页面。
- 接口与数据格式见 `CONTRACT.md`。
- 修改宿主代码后，在插件管理里关闭再启用本插件即可重新加载；仅改客户端代码时刷新页面即可。
